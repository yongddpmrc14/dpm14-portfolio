# คลังผลงาน ศูนย์ ปภ. เขต 14 อุดรธานี

เว็บแอปสำหรับบันทึกภาพและรายละเอียดการปฏิบัติงานของเจ้าหน้าที่ เชื่อมต่อกับฐานข้อมูล Supabase จริง (ไม่ใช่ต้นแบบทดลองอีกต่อไป)

## เชื่อมต่อกับ Supabase อะไรอยู่แล้วบ้าง
- Project URL และ publishable key ถูกใส่ไว้ใน `src/supabaseClient.js` แล้ว
- ต้องมีตาราง `portfolio_entries` และ storage bucket ชื่อ `portfolio-images` (แบบ public) ในโปรเจกต์ Supabase อยู่แล้วก่อนใช้งาน

## รันดูในเครื่องตัวเอง (ถ้ามี Node.js ติดตั้งไว้)
```bash
npm install
npm run dev
```
แล้วเปิดลิงก์ที่ขึ้นในเทอร์มินัล (ปกติคือ http://localhost:5173)

## เอาขึ้นเว็บจริงด้วย Vercel (แนะนำ ฟรี ไม่ต้องมีเซิร์ฟเวอร์เอง)

1. สร้างบัญชี [GitHub](https://github.com) (ถ้ายังไม่มี)
2. สร้าง repository ใหม่ แล้วอัปโหลดโฟลเดอร์นี้ทั้งหมดขึ้นไป (ลาก-วางไฟล์ผ่านหน้าเว็บ GitHub ได้เลย ไม่ต้องใช้คำสั่ง git ก็ได้)
3. สร้างบัญชี [Vercel](https://vercel.com) โดยกด "Sign up" แล้วเลือกเข้าสู่ระบบด้วยบัญชี GitHub
4. ในหน้า Vercel กด **Add New → Project** แล้วเลือก repository ที่เพิ่งอัปโหลด
5. ปล่อยค่าเริ่มต้นทั้งหมดไว้ (Vercel จะจำ Vite ได้เอง) กด **Deploy**
6. รอประมาณ 1-2 นาที จะได้ลิงก์เว็บไซต์ เช่น `https://dpm14-portfolio.vercel.app` — ใช้ลิงก์นี้แจกให้เจ้าหน้าที่ในศูนย์เข้าใช้งานได้เลย

ทุกครั้งที่แก้ไขโค้ดแล้วอัปโหลดขึ้น GitHub ใหม่ Vercel จะ build และอัปเดตเว็บไซต์ให้อัตโนมัติ

## ข้อควรทราบ
- ตอนนี้ทุกคนที่มีลิงก์เว็บสามารถเพิ่ม/ลบผลงานได้ทันที ยังไม่มีระบบล็อกอิน เหมาะกับใช้ภายในศูนย์ที่ไว้ใจกันได้ก่อน
- รูปภาพจะถูกย่อขนาดในเบราว์เซอร์ก่อนอัปโหลดขึ้น Supabase Storage อัตโนมัติ เพื่อประหยัดพื้นที่
- ปุ่ม "ลบผลงานนี้" จะลบทั้งข้อมูลและรูปภาพออกจาก Supabase ถาวร กู้คืนไม่ได้
